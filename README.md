# 英语随手读 · English Lens

小米14等 ARM64 安卓手机的英语拍照点读测试版。

**[点击下载 APK 安装包](https://github.com/melaniedramos356-art/english-lens/releases/download/v0.1.0-test/EnglishLens-0.1.0-test.apk)** · [查看发布页面](https://github.com/melaniedramos356-art/english-lens/releases/tag/v0.1.0-test)

下载后在手机打开 APK 安装。0.1.0 使用调试签名，仅供个人试用。完整源代码在 `EnglishLens-source.zip` 中，解压后可用 JDK17 / Gradle8.7 / AndroidSDK35 构建。代码和词典均已包含，不需收费 API Key。

## 能做什么

拍照/导入图片 → 手指框选 → 英文识别 → 核对或修改 → 整句朗读/慢速/停止 → 中文翻译 → 点击单词查看释义、音标、近义词、形近词、词形变化。

内置约9万英汉词条与词形索引。语音使用手机英语 TTS 引擎；没有英语语音时会提示打开设置。近义词按词典义项收录，不能随意替换；形近词只是拼写接近。当前不含 AI 逐词语境判断、完整中文语法辅导或完整例句库。

## 免费与网络

无广告、无内购、无需填写 API Key。MyMemory 匿名免费翻译通常为每天5000字符、单次500字节，出口 IP 可能共享额度；额度不足时停止，不转付费。中国大陆网络访问翻译服务和 GitHub 的稳定性尚未验证，不能承诺始终可用。已验证本机构建环境中的翻译请求成功。

## 隐私

照片在手机识别，本应用不上传照片。翻译前确认后只发送输入框文字至 MyMemory（境外服务），服务方会接收文字及 IP；勿提交敏感内容。可撤回联网授权。没有账号、通讯录、定位、麦克风或全部相册权限。语音引擎的联网处理由手机设置决定；Google ML Kit 可能按其条款收集设备/性能诊断数据。完整说明见源码内 README 和应用内说明。

## 验证范围

已通过 APK 编译、5项框选坐标测试、Android lint（无错误）及APK签名校验。**尚未经过小米14真机验证**。具体记录见 `VALIDATION.md`。安全检查不能等同于绝对零漏洞保证。

源码压缩包的组织方式是本次网页上传方式的结果。Actions 会解压源码并执行编译、单元测试和 lint，可下载构建产物；工作流生成的调试签名与本机测试包可能不同，换包前可能需要卸载旧测试版。

第三方数据：ECDICT（MIT）、Princeton WordNet，许可文件已随源码保留。依赖：Google ML Kit 和 AndroidX，适用各自许可条款。
